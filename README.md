# Sign Up — Form Validation

A polished sign-up form with live validation and a simulated OTP flow, built with pure HTML, CSS, and JavaScript.

## Features

- Email validation with inline error messaging
- Password rules checklist: 8+ characters, uppercase, lowercase, and a number
- Confirm-password matching
- Show/hide password toggles
- Submit button enabled only when the form is valid
- Simulated 6-digit email verification modal (the code is printed to the browser console)
- OTP auto-advancing inputs, paste support, resend timer, and success/reset flow
- Social login buttons (Google / GitHub / Microsoft) showing what a real OAuth integration would require
- Fully responsive and keyboard accessible

## Notes

- Email delivery and OAuth providers are simulated for demonstration only.
- To test the OTP step, open the browser console after submitting and copy the generated code.

## Run

Open `index.html` in a modern browser.
